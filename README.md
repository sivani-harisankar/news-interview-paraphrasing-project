# news-interview-paraphrasing-project
Replicating the study "What's Mine becomes Yours: Defining, Annotating and Detecting Context-Dependent Paraphrases in News Interview Dialogs" by Wegmann et al., 2024. Testing the DeBERTA v3 classifier model on one existing dataset, the transcript of the Rogan-Musk interview from kaggle, as well as the Conan-Obama interview sourced from Youtube.
